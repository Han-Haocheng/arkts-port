# C / C++（NDK 原生库）

**状态：受限**

## 先问一个问题：有没有源码？

| 情况 | 建议 |
|---|---|
| **有源码** | 别转写。用 **OHOS NDK**（`$SDK/native/llvm` + `sysroot`）重新编译成 OHOS 的 `.so`，Java/Kotlin 侧通过 NAPI 调用 |
| **无源码**（只有 ARM `.so`） | 基本不可行：bionic → musl 的 ABI 不兼容，反编译再重写成本极高 |

## 什么时候才走转写

只有**纯算法库**（编码/解码、压缩、数学、协议解析）且逻辑不依赖指针运算和内存布局时，才考虑 C → TS。

## 分诊

耦合判据：`#include <android/`、`<jni.h>`、`<GLES*>`、`<SLES*>`

## 转写注意

- 指针 → 数组 + 索引；手动内存管理 → GC，语义会变
- 未定义行为（越界、有符号溢出）在 TS 里表现不同，必须用测试兜住
- 结构体布局/padding 相关的代码不要转
